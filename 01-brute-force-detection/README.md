# Brute Force Detection with Splunk

## Project Description

This project demonstrates how to detect and investigate repeated failed login attempts using Splunk SIEM in a controlled cybersecurity lab environment.

Authentication logs are collected from a test system and sent to Splunk for analysis. Detection rules are then used to identify suspicious login activity and generate security alerts.

## Project Objectives

- Collect authentication logs from a test system.
- Send logs to Splunk SIEM.
- Detect repeated failed login attempts.
- Identify the source IP address and targeted user account.
- Create detection rules in Splunk.
- Generate security alerts.
- Investigate suspicious activity.
- Determine True Positive or False Positive.
- Document the investigation and findings.

## Tools

- Splunk SIEM
